# CBAT-Net
CBAT-Net: A Unified CNN–BiLSTM–MultiHead Transformer Architecture for Joint Q3/Q8 Protein Secondary Structure Prediction

This repository contains the implementation used in the paper:

"CBAT-Net: A Unified CNN–BiLSTM–MultiHead Transformer Architecture for Joint Q3/Q8 Protein Secondary Structure Prediction"

Authors: Ridwan Uz Zaman Pandit, Jagjit Singh Dhatterwal, Gyana Ranjana Panigrahi, Ramdas Khomane.

Requirements Python 3.11

Install packages

pip install -r requirements.txt

Run python main.py

Citation If you use this code, please cite the corresponding Scientific Reports publication.
